# Specs

One directory per spec: `SPEC-NNNN-short-slug/`, containing `spec.md`, `plan.md`, `tasks.md`.

A spec is merged and approved before any code is written against it. The full workflow is in
[AGENTS.md](../AGENTS.md#2-the-workflow-a-spec-merges-before-its-code).

To start one: `cp -r specs/TEMPLATE specs/SPEC-0001-your-slug`, take the next free number.
